# Security policy

`0.1.0a8` is an alpha built for development and evaluation. This policy covers reports against the current alpha. See the [qualification report](PHASE_4.md) and [roadmap](ROADMAP.md) for the outstanding gates.

## Report a vulnerability

Use [GitHub's private vulnerability reporting form](https://github.com/Andro-HM/Smackend/security/advisories/new) if the maintainer has enabled it. If the form is unavailable, arrange a private channel with the repository owner before sharing details.

Include the affected version, module flags, deployment conditions, impact, and the smallest synthetic reproduction or observed behavior needed to evaluate the report. Keep credentials, private data, session cookies and production records out of reports. Use public issues only for non-sensitive discussion.
